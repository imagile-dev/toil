A card number in a log is a reportable PCI DSS incident. The audit in October found some in debug logs (GitHub #33).
  • Never log a full card number (PAN), a CVC or a full track. Not at debug level, not in a test.
  • Mask a PAN to its first six and last four digits with maskPan() (src/mask.js, Jira SCRUM-55), e.g. 424242******4242.
  • Log the token or the payment id instead. They are enough to find anything.
  • Request and response bodies from the processor are never logged whole.
