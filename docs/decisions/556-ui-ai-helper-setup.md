# Toil UI: AI helper setup, calm first run, the stale notice, inline citations, Ask row (#556)

- **What:** the AI helper page opens on the steps (only while no helper can answer), then each helper with its state and its Install button, then "Which one answers" with Save. Models, CLI path and endpoint sit under an "Advanced" fold below it. **Why:** the Install buttons were far below a long form. **Where:** `ui/src/agent-settings.tsx`, `ui/src/agent-install.tsx`.
- **What:** the install flow, its dialog, the pinned command and the server are unchanged. **Why:** the brief said not to widen what the server runs.
- **What:** "not installed" is a calm "Not set up yet" in the info tone; the package, tested version, CLI path and npm-shim notes are behind "Details for whoever sets it up". An installed helper whose CLI can't start is "Needs one more step", with the reason on screen in the warning tone, never behind a fold (principle 4). An install that fails still shows as `.failure` in the dialog. **Where:** `helperState` in `agent-install.tsx`, `views.css`.
- **What (bug):** the chat's "No AI helper is set up yet" notice was handed to the chat whenever the session started with no agent, whatever the helpers' state, so it stayed after one could answer; only the questions were re-enabled. It is now shown only while no helper can answer, the chat reads the helpers on mount and whenever the page moves while that notice is up, and an installed helper that can't start yet gets its own wording. **Where:** `ask.tsx`, `guided.tsx`.
- **What:** citations in answers are plain links, `ADO 152 Store tokens in the vault…`, with the title cut at 32 characters; the full title, source name and status are in the existing tooltip (hover or keyboard focus) and the status is in the link's accessible name. **Why:** the tooltip is the project's pattern, but it never opens on touch, so on a phone the status is one tap away on the item page. **Skipped:** a tap-to-open popover for touch. Short names: ADO, GH, BB; Jira, Jenkins and OpenShift keep theirs. **Where:** `items.tsx`, `format.ts` (`sourceShort`), `analysis.css`.
- **What:** the AI helpers button sits on the Ask field's row, same height, with no `margin-left: auto`. **Why:** it had the tabs row's bottom margin and floated to the right. At 375px the Ask button still wraps under the field, as before.
