# Toil UI says it in plain copy, with no terminal in it (#561)

- **What.** Toil UI's screens no longer show terminal commands, environment variable names or file paths as copy. Gone: the "Runs `toil …`" line under every Settings form (the `runs` prop of `ChangeForm` is deleted, with every caller's `runs=`), "From `toil connections list`", "Saves: area github, baseUrl …", `TOIL_CONN_*` and `TOIL_TIMEOUT_MS`, the config file's location, the Toil project file's path, `--allow-write`, `--remove` and `--clear`, the sample-data command on the first run, and the request path in a connection test's sentence. A login reads **Saved on this computer** or **Set outside Toil UI, so it can't be changed here**.
- **Why.** The maintainer's decision, 2026-11-09: Toil UI's users are product owners and managers, not developers. A command line on every form made the app read as a terminal wearing a page. Principle 11 already asks for words a person can act on; this names the audience.
- **Where it is not removed.** Error messages and their fixes stay (principle 4), worded plainly; an error toil itself worded is kept as toil said it, including the secret check's note about an environment variable, which is toil's own text. A thing only a terminal can do is now said honestly as "Toil UI can't do that yet" (removing a person, clearing a work-in-progress limit or an Analyze setting), never as a command to type.
- **The exception: approval cards.** A proposed change shown before a person presses Run still shows what will run, because that is what they are approving. Left as they were: the proposal cards (`ui/src/components/proposal.tsx`, `ui/src/proposal.ts`), the Board's move proposals, the assignment queue's proposals (`ui/src/assign/`), the setup guide's suggestion with its Run this (`ui/src/components/guide-panel.tsx`), the AI helper install dialog (`ui/src/agent-install.tsx`), and the worklog's list of proposals.
- **A source stays on screen (principle 4).** A panel's "Fed by `toil jira issue search` ×8" is now "From Jira", with each tool and how many reads it took one step in. The tool and the count are the evidence; the command name was not.
- **Settings polish done in the same slice.** One title, **Settings**; General opens first (`#/settings/general`, with `#/settings/toil` kept as an alias and every older address still landing); Wipe the cache moved under General, Advanced, with the bounds and time limit; the connection form opens from an **Add a connection** button; tools have plain names with no id in brackets; the Default badge shows only where a tool has more than one connection; Usage is a short summary with one **More detail**, and no longer counts Toil UI's own background calls; the agent's token usage and caps moved to Usage (`#/settings/agent/caps` still lands on the caps); the AI helper page has one Save; and the three motion controls are one **Motion** select that writes the same stored keys.
- **Toil UI's own calls are left out by caller, on the page.** `audit stats` can filter to a caller but not away from one, so the page asks for each summary cross-tabbed with the caller and adds up the rest (`ownGroups`, `ownTotals` in `ui/src/usage.ts`). The medians of added-up groups cannot be added, so time per call is shown per door, from the doors summary, and not in the totals.
