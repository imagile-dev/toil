# Context Overflow glossary links in tooltips, and a Learn menu (#418)

- **Glossary lines go in the (i)'s popover, not its hover tooltip.** A tooltip closes when focus or the pointer leaves the (i), so a Read more link in one can't be reached by keyboard or touch (`ui/docs/help.md`), and five definitions in a hover box would cover the screen. The hover tooltip keeps toil's one or two sentences; pressing the (i) shows them, then each term's first sentence and **Read more on Context Overflow**.
- **The glossary lives on the help topics, not in a second table.** `HelpTopic` gains an optional `glossary` list of `{ term, slug, text }`, and `LEARN` and `LEARN_SITE` sit beside `HELP` in `ui/src/help.ts`, so the topic table's shape is unchanged for #419. Each term belongs to one topic, and the test says so.
- **Each place in the issue's table got the nearest (i), adding one only where there was none.** Usage: `model-usage` (the four token kinds) and `caps` (context window, effort). Agent: the `agent` topic on Settings, Agent. Assign modes: a new (i) beside the Assign dialog's **Mode** label, on the existing `assignments` topic. Stale sessions: a new `stale` topic, its (i) at the end of Renew all stale's first line, not on every stale badge. Ask and Analyze: the chat's existing **About these answers** (i), from a new `answers` topic. The agent switcher's popover carries no glossary; Settings, Agent has the same terms.
- **Model's line is its first two sentences.** Its first sentence is "The parameters.", which says nothing on its own.
- **Help is a menu while learning links are on**, holding **Help for this view** and then **Learn**'s four modules, and the plain link it was while they're off. The header gets no new control, which keeps it to principle 11's quiet screens; the cost is one more press to reach the docs.
- **Learn in the agent's empty chat is one Learn button** that opens the same four links in a popover, rather than four links on the page.
- **The setting is kept in this browser** (`toil-ui.learning` in localStorage), like motion and the theme, never in toil's config or Toil UI's data folder: it is a per-viewer preference.
- **The welcome menu's Learn prints each link on a line of its own** under its label, so an 80-column terminal never cuts a URL short. It also lists the glossary itself, which `skills/toil/core.md` points to.
- **The site's help-link check is unchanged.** `site/scripts/check-help-links.mjs` checks only the docs anchors, and nothing in this repository checks Context Overflow's links live, so no check fails on the 404 GitHub Pages sends with its app shell. The slugs are checked offline against `ui/test/glossary-terms.ts`.
