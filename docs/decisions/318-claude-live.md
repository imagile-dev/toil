# Toil UI's agent features, run live on Claude (#318)

- **Claude ran on Haiku (`haiku`, served as `claude-haiku-5-5`).** Every answer's label, every usage record, every assignment's record and both SDK probes were checked for that model, and none named another. The README's "Ask with Claude, on Haiku" note, from #317's PR, already says how to pick it, so it is unchanged.
- **The sign-in was read, never refreshed.** `dev-real.mjs` passed the unexpired access token in `~/.claude/.credentials.json` as `CLAUDE_CODE_OAUTH_TOKEN`; the two probes did the same. The file's modification time was the same before and after the run.
- **A Claude step's usage takes `message_delta`'s figures.** Claude Code hands over each assistant message with the usage of its `message_start`, so a step that called a tool read 24 output tokens where the API counted 72. A finished answer was right anyway, because the result's `modelUsage` replaces the steps, but a stopped or capped run kept the low figures, and a token cap counted them mid-run. The adapter now remembers the streaming message from `message_start` and folds the `message_delta` usage into its step, merged by message id as before.
- **An assignment records its model when it starts.** `startedOn.model` was filled from the finished run, so an assignment a cap or an error stopped said `model: null` though Settings had given the adapter a model (Copilot's capped run showed the same). The runner now takes the model from the host's adapter choices when the run starts, and a finished run still confirms it.
- **`total_cost_usd` is captured as the per-model `costUSD` the ledger already stores.** A probe straight through the SDK showed `total_cost_usd` equal to the sum of `modelUsage[*].costUSD`; storing it per model keeps the model on each row, so no second, unattributed figure was added.
- **A dollar cap for Claude stops the next question, not the current one.** Claude reports cost only with the result, as Codex's rates apply only to a finished turn, so a per-chat dollar cap refuses the chat's next question, which is what ran live. A token cap stops a run partway. This is the existing design, recorded here because it is what a person sees.
- **No issue was filed.** Nothing differed from Codex beyond the fixes above. The answers' content (Haiku guessing that toil can't remove a label, a light theme voice) is the model's, not the adapter's.
- **The transcripts are excerpts in `ui/docs/live-runs/claude.md`,** as for Copilot. The raw records, with session ids and the full prompts, stay outside the repository.
