# Toil UI's words and fonts (#561)

- **Plain words are always on, with no switch** (the maintainer's call, 2026-11-05). The Settings card, the palette entry, `?words=`, the `toil-ui.words` key and `data-words` are gone. `usePlain()` and `pw(standard, plain)` stay so about thirty call sites didn't churn; `pw` returns the plain text, and the dead standard branches are left where collapsing them was not trivially safe.
- **Functional versus flavour.** `src/wording.ts` splits the keys. Functional (read to act or to find a thing by name): the page eyebrows, the Ask bar's placeholders, and the status line's source and timing words. Flavour (nothing depends on it): ledes, notes, empty-state sentences, loading lines, the "nothing changed" note and the status line's "writing" word. I put `status.cache`, `status.live` and `status.registry` on the functional side because they say where a figure came from (principle 4), though they read like progress text; `status.writing` is progress, so it is flavour.
- **A theme's `terms` no longer reach a tab, heading, field or flag.** `themed()` returns the real word. `terms` stay in the manifest for the theme's moments (Realm's build events), which the moments test still holds. Dead code that rendered "Natural 20 (passed)" beside a build's state was removed.
- **Eight flavour keys added**, each worded in every theme: `empty.briefings`, `loading.briefings`, `loading.briefing`, `loading.analysis`, `loading.card`, `loading.agents`, `loading.audit` and `note.unchanged`. Themed wording stays off by default (#552), so a new person sees the plain text; this was left alone.
- **Fonts are a per-browser choice, curated from bundled files only.** `src/fonts.ts`; the pick is inline custom properties on the root, so it outranks the theme's stylesheet without touching colour or art. Eight pairings; a theme may declare `fontPairs` and `defaultFontPair`, and none does yet. The pick lives in the browser (`toil-ui.font`), not in toil's config, because only the theme is toil's own setting (#427).
- **Small fixes found on the way:** the item page's insight labels now use the same plain labels as the board's chips; the board card's menu item and the palette's default-agent entry read "AI helper"; a panel's source for the Toil project list reads "your saved Toil projects" (it checked an area name that no longer exists).
- **Later rename:** "AI helper", as worded above, later became "AI agent" everywhere (3c76fd63).
